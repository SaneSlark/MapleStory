游戏介绍

本包使用大陆 CMS072 客户端，配套本地服务端和数据库。
从彩虹岛的新手冒险开始，探索地图、完成任务、打怪升级、学习技能和收集装备。
包含拍卖综合服务等自定义功能；部分遗留任务和脚本仍可能存在兼容差异。
游戏介绍与操作指南也可打开Other\help.html 查看。
本文件中的根目录指MapleStory072；组件及存档不能与062或079混用。

一键启动

双击根目录 MapleStoryPortable.exe，在 Windows 提权提示中允许运行。
启动器自动完成：
  1. 检查 Data\mysql；仅在现有存档缺失时使用 App\DefaultData\mysql 初始模板。
  2. 检查同目录启动器互斥及端口归属，避免重复启动或误关闭其他程序。
  3. 启动包内 MySQL 数据库，再启动登录、频道、商城等游戏服务。
  4. 服务就绪后以管理员权限打开客户端，连接本机 127.0.0.1。
  5. 游戏退出后关停本次启动的服务，并正常关闭数据库。
启动器使用黑底白字的状态窗口，内容自动更新；显示区域不能选择、点击或使用鼠标滚轮滚动。
游戏正常或异常退出后，启动器完成关停会自动关闭；排查问题请查看日志。
初次启动请耐心等待。启动器提示关停完成后，再移动文件夹或拔出移动设备。

初始 SQL 提供账号：admin，密码：admin。
已有存档的账号、密码以实际存档为准，启动器不会重置已有账号。

客户端设置（包括保存账号）由启动器保存到 Data\settings\client-settings.xml。
删除整个 Data 后，下次启动同时重建存档并重置本包客户端设置；不会沿用电脑原有的保存账号。
游戏退出后恢复电脑原有客户端设置，日常仍需使用便携启动器进入游戏。

常用操作

- 方向键移动、爬梯；普通传送门附近按上键进入。
- 双击 NPC 对话，按提示接取和交付任务。
- 跳跃、攻击、拾取、技能和药水按键可在游戏内“键盘设置”查看及调整。
- 升级后检查属性点和技能点，按职业条件寻找导师转职。
- 领取奖励前预留背包空位；任务可能同时要求击杀数量与收集物品。
- 创建角色时若中文输入异常，可尝试微软拼音的旧版兼容模式或其他兼容输入法。

新手任务提示

- “迈向明珠港！”：先完成“麦加的请求”，再由10级及以下的初心者
  找南港的香克斯接取。确认后免费前往明珠港，再找坤完成任务。
  原奖励为130经验，两种食物各10个；领奖前请预留消耗栏空间。
- 任务交付会按任务数据扣除所需物品或清理指定任务物品。
  修复前已完成任务留下的物品不会自动追溯删除。
- 拒绝或关闭任务确认对话不会推进本次任务；完成后不能重复领奖。

删除角色

在角色选择界面选中角色，点击“删除角色”，阅读提示并确认。
本版通过启动器启用原生删除按钮和确认框，无需输入062版的固定生日。
删除会清理该角色、随身物品、技能与任务等数据；账号及账号共享库存保留。
家族族长不能直接删除，请先处理家族身份。重要角色请提前备份。
直接运行 App\MapleStory\Client\MapleStory.exe 不会安装此会话兼容补丁，
日常请始终使用根目录 MapleStoryPortable.exe。

频道、商城与拍卖

- 当前开放10个频道，可在游戏中选择或切换，角色存档共用。
- 商城使用客户端商城入口，购买前核对余额、商品价格、数量及有效期。
- 拍卖入口打开综合服务NPC，提供超级传送、排名、百货、转职、会员、
  仓库、技能、重置和清理菜单。费用、条件及奖励以实际对话为准。
- 超级传送按城镇、练级、BOSS分类，目的地按标注等级升序排列。
- 当前默认有效会员等级为最高5级，每日可领取一次100万金币工资；
  从拍卖的会员菜单领取，附加奖励与限制见菜单提示。
- 导游妮妮提供世界旅游及返程服务，出发前留意费用。
- 城镇自由市场入口要求角色达到5级。

显示模式

游戏使用客户端原生显示方式。获得游戏焦点后按 Alt+Enter 切换全屏/窗口。
启动器临时启用客户端窗口切换设置，退出时恢复原值；异常退出留下的恢复
记录在下次启动时处理。不强制窗口大小，不叠加第三方窗口化渲染层。
旧客户端的显示效果仍取决于系统、显卡驱动和DirectX图形支持。

便携与存档备份

- 复制整个便携包，可移动到其他盘符或含中文、空格的目录。
- 包内自带x86 Java 7与MySQL 5.7，不依赖系统安装的Java/MySQL。
- 启动器需要Windows及.NET Framework 4.x；无需安装现代.NET 6/8/9。
- 换电脑仍需满足旧客户端图形运行条件，不能仅靠提权保证全部兼容。
- 游戏进度保存在 Data\mysql\，不要删除、初始化或用旧教程SQL覆盖。
- 备份：正常退出游戏，等待服务停止，再复制整个 Data\ 文件夹。
- 恢复：保持游戏及服务关闭，先另存当前Data，再恢复自己的备份。
- App\DefaultData\mysql\仅为首次初始化模板，不会随游戏进度更新。

服务端设置

配置文件：App\MapleStory\Server\settings.ini
修改后重新启动游戏服务生效；建议保持UTF-8编码。
当前配置：
  defaultVipLevel=5    默认有效会员等级，支持0～5；不降低角色已有会员等级
  channelCount=10       开放频道数，支持1～10
  expRate=20            怪物击杀基础经验倍率
  mesoRate=2            怪物掉落金币金额倍率
  dropRate=2            怪物物品掉落概率倍率，包含BOSS
  bossDropRate=3        仅用于NPC爆率查询显示，实际BOSS掉落仍用dropRate
  scrollingMessage     游戏顶部滚动公告
掉落倍率改变概率，不表示每只怪固定掉落几件物品。
彩虹岛及服务端判定的新手教学地图不额外乘expRate，角色经验增益另算。
离开彩虹岛后的普通地图会应用expRate；源码与运行程序均保留此教学地图例外。
普通WZ任务经验未接入expRate；脚本固定经验/金币奖励也不一定跟随倍率。
顶部滚动公告使用scrollingMessage；通知栏随机“小贴士”由事件脚本发送。
数据库及连接参数也在该文件中，日常游戏无需修改。

常见问题与日志

- 启动失败：阅读启动器提示及 Data\logs\launcher.log。
  其他程序占用端口时，先确认并关闭对应程序，再启动本包。
- 删除按钮未显示：确认使用最新MapleStoryPortable.exe，关闭游戏后重新启动。
- 任务无法交付：核对接取状态、前置任务、击杀数量、收集物品和背包空位。
  “迈向明珠港”请先找南港香克斯接取，再找明珠港的坤交付。
- 打怪经验未达到10倍：确认已重启服务端，并检查是否仍在彩虹岛或教学地图。
  此类地图按现有规则不应用配置的经验倍率；任务奖励也不使用expRate。
- 领取经验直接掉线：已修正部分经验计算和提示封包问题，但瑞恩领奖时的
  无提示掉线尚未复现确认根因。请保留发生时的server.log及具体领奖步骤。
- 黑屏或图形初始化报错：检查旧客户端所需图形支持，并尝试切换显示模式。
- 安全软件拦截：记录被拦截文件、检出名称和来源后核查。
  062版的客户端来源、检出结论和注册表处理办法不能直接套用到本包。
- 反馈问题时提供地图、NPC/任务名称、角色、频道、操作步骤、截图，
  并保留 Data\logs\server.log 与 launcher.log；不要发送账号密码。

开发与维护

布局检查：MapleStoryPortable.exe --verify-layout
仅核对目录和必要文件，不启动游戏服务。
服务检查：MapleStoryPortable.exe --verify-services
会启动数据库及游戏服务并验证关停；维护测试应使用独立存档副本。
启动器源码：Other\Source\build\Launcher.cs、LauncherDisplay.cs
构建部署：Other\Source\build\BuildLauncher.exe --deploy
日常启动、检查及关停由C# EXE执行，不依赖PowerShell或Python。
资源与玩法修复以本包CMS072客户端为依据，历史维护记录见根目录AGENTS.md。

Other目录规范

Other根层统一保留以下内容：
Backups：修改后的回退文件、历史版本及验证记录，按任务或日期分类。
Source：参与编译的源码、工程文件和build构建输出。
Tools：实际使用的维护、编译和资源工具及依赖。
help.html、使用说明.txt：本版本玩家说明，内容同步维护。
