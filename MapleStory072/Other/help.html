游戏介绍

冒险岛是一款横版卷轴角色扮演游戏。你将从新手成长为冒险家，在不同地图中打怪升级、收集装备、学习技能，并通过 NPC 对话与任务了解这个世界。战士、魔法师、弓箭手和飞侠拥有不同的战斗方式，可以按自己的喜好选择发展路线。

本包以大陆 CMS072 客户端为依据，配套本地数据库与服务端，适合在自己的电脑上体验旧版冒险岛。包含原有冒险内容及拍卖综合服务等自定义功能；部分任务、脚本和高版本遗留内容仍可能存在兼容差异。

开始游戏

  1. 双击根目录的 MapleStoryPortable.exe，在 Windows 提权提示中允许运行。
  2. 等待启动器准备存档、启动数据库与游戏服务，然后自动打开客户端。首次启动可能需要更长时间。
  3. 使用已有游戏账号登录，选择世界与频道，再选择角色或点击“创建角色”。账号密码以你的存档为准。
  4. 进入游戏后，按新手 NPC 的提示逐步熟悉移动、攻击、任务与装备。

日常请通过便携启动器进入游戏。角色删除按钮等客户端兼容功能由启动器在本次游戏会话中启用。

启动器采用黑底白字的状态窗口，内容自动更新；显示区域不能选择、点击或用鼠标滚轮滚动。游戏正常或异常退出并完成关停后窗口自动关闭，排查问题请查看日志。

退出时使用游戏内的退出功能，等待启动器完成数据库与服务端关停后，再关闭电脑、移动文件夹或拔出移动存储设备。

保存账号等客户端设置随包保存在 Data/settings/client-settings.xml；删除整个 Data 后，下次启动重新初始化存档和本包客户端设置。游戏退出后，启动器恢复电脑原有客户端设置。

操作与成长

操作说明
移动与攀爬方向键左右移动，上下攀爬绳索或梯子；普通传送门附近按上键进入。
跳跃、攻击与拾取通过游戏内“键盘设置”查看或调整对应按键，也可以安排技能与药水快捷键。
对话与菜单双击 NPC 打开对话，按提示选择选项；Tab 可切换部分界面中的选项。
角色、背包与任务通过游戏菜单或已设置的快捷键查看属性、装备、技能与任务进度。
显示模式游戏获得焦点后按 Alt+Enter 切换全屏与窗口；实际显示效果取决于客户端及电脑环境。

升级后留意属性点与技能点，并在满足条件时寻找职业导师转职。装备需要满足职业、等级和属性要求；战斗前准备好恢复生命与魔法的药水。

任务可能同时要求击杀数量与收集物品，请以任务条件和进度为准。背包预留空位后再领取奖励；任务物品的掉落还会受到任务状态和掉落条件影响。

本包提供的功能

  • 10 个频道：当前开放 1～10 频道，可在游戏内选择或切换；切换频道继续使用同一角色存档。
  • 拍卖综合服务：点击客户端的拍卖入口打开服务 NPC，提供超级传送、排名、百货、转职、会员、仓库、技能、重置和清理等菜单。操作前请阅读对应费用与确认提示。
  • 超级传送：按城镇、练级、BOSS 等分类选择地图，子菜单按标注等级升序排列。标注等级用于参考，传送费用和限制以实际对话为准。
  • 导游妮妮：提供世界旅游和返程服务，前往旅游地点前请确认金币与费用。
  • 会员工资：当前默认有效会员等级为最高 5 级，可从拍卖会员菜单每日领取一次 100 万金币工资；附加奖励与限制以菜单提示为准。
  • 商城：可从游戏内进入商城，查看商品与账号余额；购买前留意价格、数量与有效期。
  • 删除角色：在角色选择界面选中角色，点击“删除角色”并确认。删除会清理该角色及其随身物品、任务等数据，请先备份存档；家族族长需要先处理家族身份。

存档、便携与设置

角色、装备、任务和账号等游戏进度保存在 Data\mysql\。备份时先正常退出游戏，等待服务停止，再复制整个 Data 文件夹。恢复时也应保持游戏与服务关闭，并先另存当前数据。

移动便携包时请复制完整文件夹，保留目录结构。包内自带 Java 7 与 MySQL 5.7；换电脑后仍需满足 Windows、.NET Framework 4.x 和旧客户端图形运行要求。

服务端设置位于 App\MapleStory\Server\settings.ini，修改后需重启游戏服务才能生效。当前配置如下：

设置当前值与作用
defaultVipLevel5；默认有效会员等级，可设为 0～5，不降低角色已有会员等级。
channelCount10；开放频道数，可设为 1～10。
expRate10；普通地图怪物击杀基础经验倍率。彩虹岛及教学地图不额外应用此倍率。
mesoRate2；怪物掉落金币金额倍率。
dropRate2；怪物物品掉落概率倍率，包含 BOSS，不表示每只怪固定掉落两件物品。
scrollingMessage游戏内顶部滚动公告。

普通任务经验和脚本固定奖励不一定跟随怪物倍率变化。bossDropRate 当前仅用于 NPC 爆率查询显示，实际 BOSS 掉落使用 dropRate。

常见问题

  • 游戏无法启动：先查看启动器提示及 Data\logs\launcher.log。端口被其他程序占用时，关闭对应程序后重试。
  • 删除按钮没有出现：关闭客户端，再通过根目录的便携启动器启动，确保使用最新部署的启动器。
  • 任务不能完成或物品不掉落：核对任务是否接取、击杀与收集条件是否全部满足、背包是否有空位。仍有问题时记录地图、NPC、任务名称和操作过程。
  • 自由市场无法进入：通过城镇自由市场入口进入时，角色需达到 5 级。
  • 更换电脑后黑屏或图形报错：检查旧客户端所需的 DirectX 图形支持，并尝试 Alt+Enter 切换显示模式。
  • 遇到异常如何反馈：保留截图和 Data\logs\server.log，写明角色、地图、频道以及能重现问题的步骤。
