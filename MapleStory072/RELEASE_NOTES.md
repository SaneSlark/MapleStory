# CMS072 v0.7.2.5

Release 标题与标签：`v0.7.2.5`

## 本次更新

- 恢复天空之城、雪域、地球防御本部和阿里安特等商店入口，按本包历史目录补齐商品，保留正常价格和任务交付。
- 补齐洛尼及另外 35 个 NPC 的普通任务入口，核对地图落点、前后交接、原条件、扣物及奖励；缺少规则或物品来源的内容继续保留。
- 恢复月妙组队任务的入口、种花、保护月妙、收集年糕、通关、退出及兑换衔接。
- 恢复一代怪物嘉年华六个场地的匹配、CP 操作、复活、胜负结果、退出清理和纪念币兑换；客户端没有的二代嘉年华保持关闭。
- 补齐天空塔／女神塔的房间、碎片、女神像、精灵爸爸、奖励出口等兼容流程；修正放置 20 个云朵无反应、易克重复生成、条件不足提示和相关 NPC 退出选项。
- 修正飞镖／子弹商店的图标数量：显示每组原生容量，与实际购买数量对应；补充单价改为完整编码，使客户端值与服务端计费值一致，保留商品目录价格。
- 调整武陵道场宽屏顶栏，将两侧血条及其间独立的数字倒计时纳入同一居中父坐标，保持原比例和内部布局；支持配置 `CenterDojoHud=0` 后完整重启客户端关闭该调整。
- 同步当前启动器及运行组件，保留自动最小化行为，撤回试验联机配置。

## 验证与保留事项

- 3336 份运行脚本语法检查通过；NPC 对话、任务动作、组队流程、实际物品掉落触发、商店数量／扣款及相关退出路径均有对应隔离检查。
- 飞镖数量与道场父坐标调整通过 x86 执行／COM 检查；最新道场独立数字层调整通过 509 项、10 种分辨率检查，用户已于2026-11-05确认完成本轮游戏实测。
- 组队玩法中部分房间组合、小碎片换算等沿用本包兼容模型，不宣称全部为官方原版规则；未知的固定通关经验、历史活动奖励及手镯好感度条件没有自行编造。
- 缺少客户端资源、专用脚本或可靠物品来源的任务／活动继续保留关闭；不保证所有历史任务、NPC 或玩法均已恢复。
- 未覆盖用户账号、角色、背包或任务进度，现有倍率保持。

## 下载与更新

- 安装包与 SHA256 校验文件由 GitHub Actions 使用已提交的运行组件自动构建、上传并发布，本地不构建安装包。
- 下载 `MapleStoryPortable_v072_SimpChinese.paf.exe`；推送或工作流启动不等于安装包已发布。

- 完整重启服务端和客户端，使新 JAR、脚本和代理 DLL 生效；旧组队实例不会由文件替换自动迁移，复测应重新开一轮。
- 安装包沿用现有过滤规则，不包含个人存档、本地源码、维护备份、README 或帮助文档；说明文件保留在版本仓库。
