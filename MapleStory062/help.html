MapleStory Portable（冒险岛 GMS v062 单机便携版）

一键启动

双击 MapleStoryPortable.exe：自动启动数据库、世界服、登录服、频道服，随后打开默认全屏游戏客户端；退出游戏后自动正常关闭全部服务。账号 admin，密码 admin。

便携说明

  • 本机已验证复制到含中文和空格的新路径后，服务可启动并正常关闭。换电脑还需满足 Windows/.NET Framework 4.x 和旧客户端的图形兼容要求。
  • 游戏进度保存在 Data\mysql\；删除后下次启动自动从 App\DefaultData 初始存档重开。备份进度 = 复制 Data 目录。
  • 新机器上如被安全软件拦截，参阅 Other\使用说明.txt 的「安全软件拦截」一节。

全屏 / 窗口切换

游戏默认原生全屏。游戏获得焦点后按 Alt+Enter 切换到窗口模式，再按一次切回全屏。启动器不再强制窗口大小或为窗口化重启游戏。

其他程序占用端口时，启动器会停止并提示；只回收路径和端口均确认属于本包的遗留服务。运行日志与存档留在 Data；启动器源码在 Other\Source\build\Launcher.cs，文档在 Other（使用说明.txt、更新日志.md、新手入门 GM 资料）。

启动画面

启动 Nexon 画面已替换为 MapleStory 枫叶 logo（2026-09-28 更新，图案已按屏幕中心对齐）。换图工具：Other\Tools\WzLogoPatch\bin\WzLogoPatch.exe（fit 缩放居中、replace 替换并自动校验）；还原：把 Other\Backups\UI.wz.before-nexon-logo-20260928 复制回 App\MapleStory\Client\UI.wz。

目录结构

  • MapleStoryPortable.exe — 一键启动器（源码 Other\Source\build\Launcher.cs）
  • App\DefaultData\mysql\ — 初始存档
  • App\MapleStory\Client\ — 客户端与 WZ/DLL
  • App\MapleStory\Runtime\ — Java 与 MySQL 程序
  • App\MapleStory\Server\ — 服务端 JAR、脚本、XML、配置与密钥
  • Data\mysql\ — 游戏进度　Data\logs\ — 服务日志
  • Other\Source\ — 服务端源码　Other\ — 文档与 GM 资料　Other\Tools\ — WZ 修改工具

工具项目清单：2026-10-05 清单；详细说明：使用说明。
